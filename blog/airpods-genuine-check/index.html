에어팟 정품 확인 방법: 일련번호 조회와 가품 구별 포인트

2026.10.28 · 전자몰

요약 아이폰 설정에서 에어팟 일련번호를 확인한 뒤 애플 보증 상태 확인 페이지(checkcoverage.apple.com)에 넣어 조회합니다. 정품이면 모델명과 보증 상태가 나옵니다. 연결 팝업 애니메이션은 가품도 흉내 내므로 정품 판단 기준이 되지 않습니다.

1. 일련번호 찾기

  • 아이폰: 에어팟을 연결한 상태에서 설정 → Bluetooth → 에어팟 옆 (i) 에 일련번호가 나옵니다. 번호를 누르면 왼쪽·오른쪽 유닛 번호가 따로 보이는 경우도 있습니다.
  • 본체: 뚜껑 안쪽이나 본체 겉면에 일련번호가 인쇄되어 있습니다.

2. 애플 보증 상태 조회

애플 보증 상태 확인 페이지에 일련번호를 입력합니다. 정품이면 제품 이름(예: AirPods Pro 2세대)과 구입일 확인 여부, 보증 상태가 표시됩니다. 번호를 인식하지 못하면 다시 확인이 필요합니다.

3. 가품에서 자주 보이는 차이

  • 설정 화면에 펌웨어 버전, 공간 음향 같은 애플 전용 항목이 없거나 이상하게 표시됨
  • 본체 인쇄 글씨가 번지거나 두께·간격이 고르지 않음
  • 노이즈 캔슬링·주변음 허용이 메뉴에는 있지만 실제 차이가 거의 없음

낱개 구매 시 일련번호가 다른 이유

한쪽 유닛이나 본체를 낱개로 바꾸면 각 부분의 일련번호가 원래 제품과 달라집니다. 유닛과 본체가 각자 일련번호를 가지는 구조라 정상입니다. 전자몰은 정품만 취급하며 모든 제품을 기능 검수 후 판매합니다.

자주 묻는 질문

보증 조회에서 "구입일 확인 필요"가 나오면 가품인가요?

아닙니다. 애플에 구입 기록이 등록되지 않았다는 뜻으로 정품에서도 나옵니다. 제품명이 정상적으로 나오면 정품입니다.

중고 에어팟도 애플 보증을 받을 수 있나요?

보증 기간이 남아 있으면 소유자와 관계없이 일련번호 기준으로 적용됩니다. 조회 결과의 보증 상태를 확인합니다.
