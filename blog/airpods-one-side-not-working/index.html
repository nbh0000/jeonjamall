에어팟 한쪽만 안 들릴 때·소리 작을 때 확인할 5가지

2026.10.29 · 전자몰

요약 충전 상태 → 아이폰 좌우 밸런스 설정 → 스피커 망 이물질 → 본체 재설정 순서로 확인합니다. 이렇게 해도 한쪽 소리가 안 나거나 지지직거리면 그 유닛의 고장일 가능성이 높아 같은 모델의 한쪽 유닛만 바꾸면 됩니다.

1. 두 유닛 충전 상태

두 유닛을 본체에 넣고 뚜껑을 연 채 아이폰 옆에 두면 각 유닛의 배터리가 따로 표시됩니다. 한쪽이 0%이거나 표시되지 않으면 본체 안쪽 충전 단자와 유닛 끝을 마른 면봉으로 닦은 뒤 다시 충전합니다.

2. 좌우 밸런스 설정

아이폰 설정 → 손쉬운 사용 → 오디오 및 시각 → 밸런스가 가운데에 있는지 확인합니다. 한쪽으로 치우쳐 있으면 그쪽 소리만 크게 들립니다.

3. 스피커 망 청소

소리가 작게 들리는 경우 대부분 스피커 망에 귀지나 먼지가 쌓인 것입니다. 마른 부드러운 솔이나 면봉으로 살살 닦고, 물이나 날카로운 도구는 쓰지 않습니다. 프로 모델은 이어팁을 빼고 안쪽 망까지 확인합니다.

4. 연결 지우고 재설정

설정 → Bluetooth → 에어팟 옆 (i) → 이 기기 지우기를 한 뒤 본체를 재설정하고 다시 연결합니다. 순서는 에어팟 재설정·연결 방법과 같습니다.

5. 그래도 안 되면

위 순서로도 한쪽이 무음이거나 잡음이 나면 유닛 내부 고장일 가능성이 높습니다. 이때는 고장 난 쪽 유닛만 같은 모델로 바꾸면 됩니다. 에어팟 유닛 낱개 보기

한쪽만 배터리가 빨리 닳는 것도 고장인가요?
